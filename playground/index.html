Detection playground

Use the password wrong to simulate a failed sign-in. Anything else succeeds.

  • Classic form login (navigates)
  • Single-page app login (no form, no navigation)
  • Two-step login (email, then password)
  • Signup with confirm password
  • Password reset from an email link
  • Card payment: labels, month/year dropdowns
  • Card payment: each card field in its own iframe
  • Checkout: full name, email, address in an iframe (like Faherty Second Wave)
  • Forgot password: username, then a new password in the same tab
  • Login popup in a frame from another site, email then password (like espn.com)
