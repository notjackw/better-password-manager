Import passwords

Import a CSV file exported from another password manager.

  • Chrome: Settings → Autofill and passwords → Google Password Manager → Settings → Export passwords
  • Safari / Apple Passwords: File → Export → All Passwords
  • Firefox: Passwords → ⋯ → Export passwords

Logins you already have are never overwritten. If the file has a different password for a saved login, the file's version goes to Needs review so you can choose.
